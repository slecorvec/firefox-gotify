# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue.

Only the current `master` is supported.

## Scope

In scope: anything that lets content pushed to a Gotify server (message title, body,
extras, application names) run code, alter the extension's pages, open a non-http(s)
URL, or that leaks the client token anywhere else than the configured server.
